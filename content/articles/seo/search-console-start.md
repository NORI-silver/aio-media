Google Search Console(サーチコンソール)は、**自分のサイトが Google 検索でどう扱われているかを確かめるための、Google 公式の無料ツール** です。どんな検索語で何回表示され、何回クリックされたか、ページが検索に登録されているか、問題が起きていないかがわかります。SEO も AIO(AI検索への最適化)も、まずここで現状を知ることから始まります。


たとえるなら、Search Console は **Google からとどく「サイトの通知表」** です。検索に何回出たか、何回クリックされたか、何番目くらいに出たか、そして「このページは登録できていません」といった困りごとまで教えてくれます。

{{figure:search-console-report|図1 Search Consoleでわかる4つのこと}}

ただし学校の通知表とちがって、「なぜこの順位なのか」という理由までは書いてありません。数字を見て、自分で原因を考えて直していく道具です。

## Search Consoleで何がわかる? [初級]

最初に覚えておきたい画面は4つです。

| 画面 | わかること |
|---|---|
| 検索パフォーマンス | どの検索語・ページで、何回表示・クリックされたか、平均の掲載順位 |
| ページ(インデックス作成) | 検索に登録されたページと、登録されていないページとその理由 |
| URL検査 | 1つのURLが登録されているか、最後にいつクロールされたか |
| サイトマップ | 送ったサイトマップを Google が読めたか |

Google アナリティクス(GA4)が「サイトに来た後」の行動を測るのに対して、Search Console は **「検索結果で見られてからクリックされるまで」** を測る道具です。

## 登録するときは「ドメイン」と「URLプレフィックス」のどちらを選ぶ? [初級]

サイトを登録するとき、2種類の「プロパティ」(Search Console に登録するサイトの単位)から選びます([Google のヘルプ](https://support.google.com/webmasters/answer/34592))。

| | ドメイン | URLプレフィックス |
|---|---|---|
| 対象 | ドメイン全体(すべてのサブドメイン、http と https の両方) | 入力したURLで始まるページだけ(http と https は別扱い) |
| 例 | `example.com` と入れると `www.example.com`、`blog.example.com` も含む | `https://www.example.com/` で始まるURLだけ |
| 所有権の確認方法 | DNS レコードのみ(ドメインを買った会社の設定画面に1行足す) | HTMLファイル、HTMLタグ、Googleアナリティクス、タグマネージャーなど |

DNS の設定を変更できるなら、**ドメインプロパティがおすすめ** です。サブドメインや http/https の違いをまとめて見られます。

このサイト(aio.shiokonbu.com)は、運営者がもともと登録していた `shiokonbu.com` のドメインプロパティに含まれています。そのため、サブドメインを新しく作っても、追加の確認なしで Search Console のデータを見られました。

## 所有権はどう確認する? [中級]

Search Console のデータは、そのサイトの持ち主だけが見られます。そのため、登録時に「所有権の確認」が必要です([Google のヘルプ](https://support.google.com/webmasters/answer/9008080))。

- **DNS レコード**(ドメインプロパティ):ドメインの管理画面(お名前.com、さくらのドメインなど)で、指定された TXT レコードを追加します。反映に2〜3日かかることがあります。
- **HTMLタグ**(URLプレフィックス):`<meta name="google-site-verification" content="…">` をトップページの `<head>` に入れます。WordPress なら SEO プラグインに入力欄があることが多いです。
- **Googleアナリティクス・タグマネージャー**:すでに GA4 やタグマネージャーを入れていて、同じ Google アカウントで編集権限があれば、それで確認できます。

どの方法でも、**確認が済んだ後もタグやレコードを消してはいけません**。Search Console は定期的に確認し続けていて、消すと所有権が外れます。担当者が変わるときに備えて、複数の人・複数の方法で確認しておくこともできます。

## 登録したら最初に何をする? [中級]

1. **サイトマップを送信する**:「サイトマップ」画面で `sitemap.xml` のURLを送ります。作り方は「[XMLサイトマップとは?](/seo/xml-sitemap/)」で解説しています。
2. **トップページを URL検査にかける**:検査バーにURLを入れ、「URL は Google に登録されています」と出るか確かめます。
3. **新しいページは登録をリクエストする**:URL検査で未登録のときは「インデックス登録をリクエスト」を押せます。1日の上限があり、押しても登録が保証されるわけではありません。ページが多い場合は、サイトマップの更新日(lastmod)を正しく保つほうが効率的です。
4. **数日〜数週間たったら「検索パフォーマンス」を見る**:データがたまるまで少し時間がかかります。

## URL検査の結果はどう読む? [上級]

URL検査は、Google が最後に登録したときのページの状態を表示します(「公開 URL をテスト」を押すと、今のページをその場で確かめられます)。このサイトで2026年11月9日に確かめた実際の結果です。

| 項目 | トップページ | 公開直後の記事 |
|---|---|---|
| 登録状況 | 送信して登録されました | 検出 - インデックス未登録 |
| robots.txt | 許可 | — |
| 最終クロール | 2026年11月9日 | まだ |
| ユーザーが指定した正規URL | `https://aio.shiokonbu.com/` | — |
| Google が選択した正規URL | `https://aio.shiokonbu.com/` | — |

読むときのポイントは次のとおりです。

- **「送信して登録されました」**:サイトマップで送ったURLが、検索に登録された状態です。
- **「検出 - インデックス未登録」**:Google がURLの存在は知っているが、まだクロールしていない状態です。公開直後のサイトではよくあることで、時間とともに進むのを待ちます。長く続く場合は、内部リンクを増やす、ページの中身を充実させるといった対策を考えます。
- **2つの正規URLが一致しているか**:一致していれば、サイト側の指定どおりに扱われています。違う場合の考え方は「[canonical(正規URL)とは?](/seo/canonical-url/)」で解説しています。
- **「登録されています」は「表示される」の保証ではない**:Google は、URL検査はすべての表示条件を確かめるものではないとしています。

### AI Overviewsでの表示はどこで見る?

Google によると、AI Overviews や AIモードでの表示・クリックは、「検索パフォーマンス」の **「ウェブ」** に含めて集計されます。さらに2026年6月には、生成AI機能向けのパフォーマンスレポートを追加したと発表しています。詳しくは「[AI Overviewsとは?](/aio/ai-overviews/)」をご覧ください。

## よくある質問

### Search Consoleは無料?

無料です。Google アカウントがあれば、だれでも登録できます。

### 登録しないと検索に出ない?

登録しなくても、Google はリンクをたどってサイトを見つけ、検索に出します。ただ、検索での状況や問題を確かめられないので、サイトを運営するなら登録しておくのがおすすめです。

### GA4と何が違う?

Search Console は「検索結果で表示されてクリックされるまで」、GA4 は「サイトに来た後の行動」を測ります。両方を連携させると、検索語ごとにサイト内の行動まで追えるようになります。

### データはいつから見られる?

登録してすぐにはデータがそろいません。検索パフォーマンスのデータは数日遅れで反映されるので、登録から数日〜1週間ほど待ってから見始めましょう。
