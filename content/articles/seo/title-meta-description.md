タイトルと meta description は、**検索結果でユーザーが最初に目にする「ページの名前」と「紹介文」** です。Google 検索セントラルは、どちらにも文字数の上限はないとしたうえで、ページごとに固有で、内容を正確に表すものにするよう勧めています。この記事では、公式ガイド(2026年11月時点で確認)をもとに書き方のルールとコツをまとめます。

## タイトルとmeta descriptionは何に使われる? [初級]

| | タイトル(`<title>`) | meta description |
|---|---|---|
| どこに出る? | 検索結果の青いリンク(Google は「タイトルリンク」と呼ぶ)、ブラウザのタブ | 検索結果のリンクの下の説明文(スニペット)に使われることがある |
| 役割 | そのページが何のページかを一言で伝える | ページ全体を要約して、クリックするか判断する材料にする |
| HTMLでの書き方 | `<title>…</title>` | `<meta name="description" content="…">` |

どちらも `<head>` の中に書きます。WordPress などでは、SEO プラグインの入力欄に書くと自動で入ります。

## 何文字で書けばいい? [初級]

Google は、タイトルにも meta description にも **文字数の上限はない** としています。ただし検索結果では、**端末の画面幅に合わせて途中で切られます**([タイトルリンク](https://developers.google.com/search/docs/appearance/title-link)、[スニペット](https://developers.google.com/search/docs/appearance/snippet))。

そこで実務では、次のように考えるのが安全です。

- **大事な言葉を前半に置く**:後ろが切れても意味が通るようにする
- **長すぎない**:このサイトでは、タイトル28〜40字、description 80〜120字を目安にしています(自動チェックで確認)
- **数字は目安であってルールではない**:切れる位置は端末や検索語で変わるので、文字数を1字単位で合わせる意味は薄い

## Googleが勧める書き方は? [中級]

### タイトル

公式ガイドのポイントは次のとおりです。

- **すべてのページにタイトルを付ける**
- **ページごとに違うタイトルにする**:同じタイトルが多いと、検索結果でページの区別がつかない
- **「ホーム」「プロフィール」のようなあいまいな名前を避ける**
- **キーワードを何度も繰り返さない**:同じ言葉を重ねても読者の役に立たず、スパムのように見える
- **サイト名は前か後ろに区切り記号をつけて1回だけ**:長いキャッチコピーを全ページに入れない
- **ページのメインの見出し(h1)と内容をそろえる**

### meta description

- **ページごとに固有の内容にする**:全ページ同じ説明文は役に立たない
- **ページ全体を正確に要約する**:キーワードの羅列や短すぎる文は向かない
- **判断に役立つ情報を入れる**:記事なら著者や公開日、商品なら価格など

### このサイトの例

この記事のタイトルと description は次のとおりです。メインの検索語「タイトル」「meta description」「書き方」を前半に置き、description では記事で答える内容を具体的に並べています。

```
<title>タイトルとmeta descriptionの書き方|文字数とGoogleのルール</title>
<meta name="description" content="検索結果に出るタイトルと説明文(meta description)の書き方を、Googleの公式ガイドをもとに解説。…">
```

## タイトルや説明文が勝手に書き換えられるのはなぜ? [中級]

検索結果に出るタイトルや説明文が、自分で書いたものと違うことがあります。これは不具合ではありません。

**タイトル**:Google はタイトルリンクを自動で作っていて、`<title>` のほかに次のような情報も使います。

- ページのメインの見出し(`<h1>` など)や、大きく目立つ文字
- `og:title`(SNS 用のタイトル)
- ページ内の文章、他のページからこのページへのリンクの文字
- `WebSite` の構造化データ(サイト名)

`<title>` が内容と合っていない、長すぎる、全ページ同じ、といった場合に書き換えられやすくなります。

**説明文**:Google のスニペットは、**主にページの本文から**作られます。検索語に合わせて本文の関連部分を見せるためで、同じページでも検索語によって表示が変わります。meta description は、それが本文より正確な要約だと判断されたときに使われます。

書き換えを減らしたいときは、タイトルと h1 の内容をそろえ、description をページの正確な要約にするのが近道です。変更してから検索結果に反映されるまで、数日から数週間かかることがあります。

## AI検索ではタイトルと説明文はどう効く? [上級]

AI Overviews や ChatGPT の検索では、タイトルや description がそのまま表示されるとは限りません。それでも次の点で重要です。

- **引用元のリンク名として表示される**:AIの回答の参照リンクでは、ページのタイトルやサイト名が出ることが多く、ここで「何のページか」が伝わらないとクリックされません。
- **AIが「どの問いに答えるページか」を判断する手がかりになる**:Google の AI 機能は、1つの質問を小さな問いに分けて関連ページを探します([AI Overviewsの仕組み](/aio/ai-overviews/))。タイトルが具体的な問いの形になっていると、その問いに答えるページだと伝わりやすくなります。
- **description と冒頭の段落をそろえる**:Google のスニペットは本文から作られるので、記事の最初の段落で結論を言い切っておくと、検索結果でもAI検索でも要点が伝わります。このサイトでは、冒頭の「この記事の結論」と description を同じ方向の内容にしています。

なお、Google は生成AI検索のために特別な書き方をする必要はないとしています。ここで挙げたことは、通常のSEOとしても正しい書き方です。

あわせて、検索エンジンに「どのURLが正しいページか」を伝える [canonical](/seo/canonical-url/) と、ページの種類を伝える [構造化データ](/seo/structured-data/) も確認しておきましょう。自分のサイトのタイトルと説明文の状態は、[AIO診断ツール](/aio-checker/) でも確かめられます。

## よくある質問

### タイトルにサイト名は入れるべき?

入れてかまいません。Google は、サイト名を入れるならタイトルの前か後ろに、「|」や「-」などの区切り記号をつけて入れることを勧めています。長いキャッチコピーを全ページに入れるのは避けましょう。

### meta descriptionを書かないとどうなる?

Google がページの本文から説明文を自動で作ります。書かなくても検索結果には出ますが、トップページや主要なページは、内容を正確に要約した description を書いておくのがおすすめです。

### 全ページのdescriptionを手で書くのが大変です

Google は、ページ数が多いサイトでは、データベースの情報(商品名・価格など)から自動で作ることも認めています。ただし、読みやすく、ページごとに違う内容になるようにします。重要なページから優先して手で書きましょう。

### タイトルを変えたら順位は下がる?

タイトルは、ページが何についてのものかを伝える大事な手がかりなので、変えると表示される検索語や順位が変わることはあります。大きく変えるときは、変更前後で Search Console の表示回数・クリック数・検索語を見比べてください。
