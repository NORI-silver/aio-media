コンバージョン計測は、**広告を見た人がサイトで購入や問い合わせなどの成果(コンバージョン)を起こしたことを、広告媒体に知らせる設定** です。Google広告は **Googleタグ**、Meta広告は **Metaピクセル** をサイトに入れるのが基本で、さらに **拡張コンバージョン(Google)やコンバージョン API(Meta)** でサーバー側や入力データからも送ると、取りこぼしが減ります。今の広告は、このデータで自動入札や配信の AI が学習するので、**計測の正確さがそのまま広告の成果を左右します**。

## なぜ計測がいちばん大事なの? [初級]

計測がないと、「どの広告から、いくらで、何件の問い合わせが来たか」がわかりません。それだけでなく、今の広告では次のことが起きます。

- **自動入札が学習できない**:Google の自動入札は、ヘルプで「コンバージョントラッキングが必要」と明記されています([Google広告の自動入札とは?](/ads/smart-bidding/))
- **間違った成果を学習する**:ページの閲覧を成果にすると、AI は「ページを見るだけの人」を増やそうとする
- **成果が少なく見える**:計測が漏れていると、本当は効いている広告を止めてしまう([広告運用のよくある失敗](/ads/ad-mistakes/))

## 何を「成果」にすればいい? [初級]

成果は、**「これが増えたら売上が増える」と言える行動** にします。

| ビジネス | メインの成果(最適化に使う) | サブの成果(参考に見るだけ) |
|---|---|---|
| EC | 購入(金額つき) | カート追加・購入手続き開始 |
| BtoB・士業 | 問い合わせ・資料請求の完了 | 料金ページの閲覧 |
| 店舗・サロン | 予約完了・電話 | 地図・ルートの表示 |
| 採用 | 応募完了 | 募集ページの閲覧 |

Google 広告では「メインのコンバージョン」と「サブのコンバージョン」を分けられます。自動入札はメインだけを使うので、**サブは参考として見るもの** に入れます。Meta 広告では、広告セットの「最適化の対象」に選んだ成果が、AI の学習に使われます([Meta広告とは?](/ads/meta-ads-basics/))。P-MAX や Advantage+ のように AI に任せる部分が大きいキャンペーンほど、この選び方が成果を左右します([P-MAXとは?](/ads/performance-max/))。

## どうやって設定する? [中級]

### Google広告

1. Google 広告の「目標」→「コンバージョン」で、成果を作る(例:問い合わせ完了)
2. サイト全体に **Googleタグ** を入れる(Google タグマネージャーを使うと管理しやすい)
3. 成果が起きたページやボタンで、コンバージョンのイベントが送られるようにする(サンクスページの表示、フォーム送信など)
4. GA4 を使っているなら、GA4 の「キーイベント」を Google 広告に取り込む方法もある(GA4 と Google 広告のアカウントをリンクする)
5. タグアシスタントなどで、テストの問い合わせが計測されるか確かめる

### Meta広告

1. イベントマネージャで **データセット(ピクセル)** を作り、サイト全体に Meta ピクセルを入れる
2. 成果のページやボタンで、標準イベント(`Purchase`・`Lead` など)を送る
3. **コンバージョン API** を設定し、サーバーからも同じ成果を送る(Shopify などのカートや、Google タグマネージャーのサーバーコンテナ、各種連携ツールで設定できる)
4. ドメインを認証し、どのイベントを最適化に使うかを確かめる
5. イベントマネージャの「テストイベント」で、ブラウザとサーバーの両方から届くか確かめる

### 拡張コンバージョンとコンバージョンAPIは何がいいの?

ブラウザのタグだけだと、Cookie の制限や広告ブロック、ページを閉じるタイミングなどで、成果の一部が広告媒体に届きません。

- **拡張コンバージョン(Google)**:Google 広告ヘルプ「[拡張コンバージョンについて](https://support.google.com/google-ads/answer/9888656?hl=ja)」(2026年11月確認)では、「より正確なコンバージョン測定と高度な入札単価設定を可能にする機能」と説明されています。フォームに入力されたメールアドレスや電話番号などを、**送る前に SHA256 でハッシュ化(元に戻せない形に変換)** して送り、ログイン中の Google アカウントと照合します。
- **コンバージョン API(Meta)**:Meta の開発者向けドキュメント([Handling Duplicate Pixel and Conversions API Events](https://developers.facebook.com/docs/marketing-api/conversions-api/deduplicate-pixel-and-server-events))では、**広告の成果を最大化するために、ピクセルとあわせてコンバージョン API を使うこと** が推奨されています。

## 重複や法律で気をつけることは? [上級]

### ピクセルとコンバージョンAPIの重複を防ぐ

ブラウザとサーバーの両方から同じ成果を送ると、そのままでは2件と数えられてしまいます。Meta のドキュメントによると、**イベント名(`event_name`)とイベントID(`event_id`)が同じなら、同じ成果として1件にまとめられます**。ピクセルの `eventID` とコンバージョン API の `event_id` に、注文番号などの同じ値を入れるのが定番です。

また、まとめられるのは **最初のイベントを受け取ってから48時間以内に届いたもの** だけです。サーバーからの送信を1日1回のまとめ送りにしている場合などは、時間差に注意します。

```html
<!-- ブラウザ側(Metaピクセル) -->
<script>
fbq('track', 'Purchase', {value: 5000, currency: 'JPY'}, {eventID: 'order-12345'});
</script>
```

```json
// サーバー側(コンバージョンAPI)で同じ注文を送るときの例
{"event_name": "Purchase", "event_id": "order-12345", "event_time": 1794211200,
 "action_source": "website", "custom_data": {"value": 5000, "currency": "JPY"}}
```

### Google広告でオフラインの成果を取り込む

BtoB のように「問い合わせ」の後、「商談」「成約」がサイトの外で起きる場合、問い合わせの件数だけで最適化すると、成約しない問い合わせまで増えることがあります。拡張コンバージョンのヘルプでは、こうした **サイトで獲得した見込み客のオフラインの成約を測る「リード向けの拡張コンバージョン」** も案内されています。成約のデータを取り込み、それをメインの成果にすると、自動入札が「成約しそうな人」を探すようになります。

### 日本の法律:外部送信規律

広告タグは、閲覧者の情報を広告媒体(外部)に送る仕組みです。2023年6月16日に施行された改正電気通信事業法の **外部送信規律** では、対象の事業者が利用者の情報を外部に送らせる場合、**送る情報の内容・送り先の名前・利用目的** を通知・公表するなどの対応が求められています([総務省「外部送信規律」](https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu.html)、2026年11月確認)。

総務省の説明では、ニュースサイトやまとめサイトなど情報をオンラインで提供するサイトは対象になりうる一方、**自社商品のオンライン販売や一般的な企業のホームページは対象外** とされています。対象かどうかにかかわらず、どのタグが何の情報をどこに送っているかをプライバシーポリシーに書いておくと、利用者の信頼につながります。

## よくある質問

### GA4のキーイベントとGoogle広告のタグ、どちらで計測すべきですか?

どちらでも自動入札に使えますが、Google 広告の成果をより正確に、早く反映させたいなら、Google 広告のコンバージョン(Googleタグ)を使うのが一般的です。GA4 は、広告以外も含めたサイト全体の分析に使い、数字の違いは「数え方の違い」と理解しておきましょう。

### サンクスページがないフォームはどう計測しますか?

フォームの送信が完了したタイミングでイベントを送ります。Google タグマネージャーのフォーム送信トリガーや、フォームツールが用意している連携機能を使います。ボタンのクリックだけで数えると、入力エラーの人まで成果に入るので注意しましょう。

### 計測を変えたら、自動入札の成果が急に変わりました

最適化に使う成果を変えると、Google 広告では入札戦略が「学習中」になります([Google広告の自動入札とは?](/ads/smart-bidding/))。計測の変更は、売上の多い時期を避け、変更した日を記録しておきましょう。

### 広告とSEOの成果を同じ画面で比べられますか?

GA4 なら、参照元・メディア別に、広告(cpc)と自然検索(organic)の成果を並べて比べられます。SEO側の数字の見方は [Search Consoleの始め方](/seo/search-console-start/) で解説しています。
