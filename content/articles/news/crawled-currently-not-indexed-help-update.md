> **ひとことで言うと**:Google を「図書館」、あなたのページを「持ちこまれた本」だと思ってください。「クロール済み - インデックス未登録」は、**司書さんが本を読んだけれど、棚には並べなかった** という意味です。今回、図書館の受付にある案内の紙が書き換わり、「**図書館はすべての本を棚に置くわけではありません。よくあることです**。大事な本なら、置かれない理由がないか調べてください」と、はっきり書かれるようになりました。
>
> ただし、本物の図書館とちがって、Google は「なぜ置かなかったか」を1冊ずつは教えてくれません。

**あなたがやること:Search Console でこの表示を見ても、慌てなくて大丈夫です。** 会社案内・サービス紹介・よく読まれる記事など、**検索に出てほしい大事なページ** がこの状態のときだけ、この記事の「大事なページがこの状態なら?」の章の手順で原因を確かめてください。

**Google は、Search Console(サーチコンソール:Google が無料で出している、サイトの通知表)のヘルプにある「クロール済み - インデックス未登録」の説明を書き換えました。** 新しい説明は「Google はウェブ上のすべてのページをインデックスに登録するわけではないため、これは多くのサイトでよく見られるメッセージであり、必ずしも注意が必要な問題を示しているわけではありません」です([ページのインデックス登録レポート|Search Console ヘルプ](https://support.google.com/webmasters/answer/7440203?hl=ja)、2026年11月10日に確認)。書き換えは、海外の SEO メディアが2026年11月3日(米国時間)に報じました。Google はブログなどでの発表はしていません。

Search Console の始め方は「[Search Consoleの始め方](/seo/search-console-start/)」で、Google がページを集めて並べるしくみの全体は「[SEOとAIOの仕組み](/aio/how-search-and-ai-work/)」で説明しています。

## 何が変わった? [初級]

{{figure:crawled-not-indexed-analogy|図1 この記事のたとえ。Google を図書館にたとえます}}

この記事では「図書館」のたとえを最後まで使います。

- **持ちこまれた本** = あなたのWebページ
- **司書さんが中身を読む** = クロール(Google のプログラムがページを見に来ること)
- **棚に並べる** = インデックス登録(検索結果に出せる状態にすること)
- **受付にある案内の紙** = Search Console のヘルプ

「クロール済み - インデックス未登録」は、Search Console の「ページ」という画面(インデックス作成 → ページ)に出る、登録されなかった理由の1つです。**Google はページを読みに来た。でも、検索に出せる状態にはしなかった** という意味です。

{{figure:crawled-not-indexed-before-after|図2 ヘルプの説明の、前と後}}

今回変わったのは、この状態の **説明の文章** です。Google の判断のしかたが変わった、という発表ではありません。

| | 前の説明 | 今の説明(2026年11月10日に確認) |
|---|---|---|
| 意味 | ページはクロールされたが、登録されていない | 同じ |
| この先 | いずれ登録されるかもしれない | (この一文はなくなった) |
| 送り直し | 送り直す必要はない | (この一文はなくなった) |
| よくあることか | 書かれていなかった | **多くのサイトでよく見られる。必ずしも問題ではない** |
| 何をすればいい | 書かれていなかった | **重要なページなら、URL 検査などで原因を調べる** |
| 報告先 | 書かれていなかった | サイト全体の不具合と思われるときは、報告フォーム |

前の説明は、海外メディアの報道([Search Engine Roundtable](https://www.seroundtable.com/google-updates-crawled-currently-not-indexed-42450.html)、2026年11月10日に確認)が引用した、書き換え前の英語版の文章です。当サイトでは書き換え前のページを直接は確かめられていないため、「報道で確認」とします。

### なぜ大事なニュースなの?

この表示を見て「サイトに問題があるのでは」と心配する人がとても多いからです。新しい説明は、**全部のページが棚に並ぶわけではないのがふつう** と、Google 自身が言い切りました。

いっぽうで、「いずれ登録されるかもしれない」という一文が消えました。**待てば必ず並ぶ、とは言っていない** ということです。大事なページなら、待つだけでなく、理由を確かめるほうに重心が移りました。

## 大事なページがこの状態なら? [中級]

{{figure:crawled-not-indexed-check|図3 大事なページが「クロール済み - インデックス未登録」のときの確かめ方}}

### 1. そのページは本当に大事か考える

まず、出ているページの一覧を見ます。Search Console の左のメニューで「インデックス作成」→「ページ」を開き、「ページがインデックスに登録されなかった理由」の表から「クロール済み - インデックス未登録」を押すと、例のURLが並びます。

次のようなページなら、棚に並ばなくても困りません。そのままで大丈夫です。

- タグやカテゴリの一覧、2ページ目以降の一覧
- サイト内検索の結果ページ
- 中身がほとんど同じ、印刷用・並べ替え用のページ

図書館でいえば、同じ本の「コピー」や「目次だけの紙」が棚に並ばないのは、ふつうのことです。

### 2. URL 検査で状態を見る

大事なページなら、Search Console のいちばん上の検索窓に、そのページのURLを入れます(URL 検査)。見るところは次の3つです。

- **最終クロール日**:Google が最後に読みに来た日。古いままなら、そのあとに直した中身はまだ読まれていません
- **ユーザーが指定した正規URL と Google が選択した正規URL**:ちがうURLになっていたら、Google は「別のページと同じ本」とみなしています。考え方は「[canonical(正規URL)とは?](/seo/canonical-url/)」を見てください
- **「公開 URL をテスト」**:今のページを Google が読めるかを、その場で試せます

### 3. Google を入口で止めていないか確かめる

新しいヘルプは、確かめることの例として「**Google のクローラーをブロックしていないか**」を挙げています。次の3つを見ます。

- **robots.txt**(ロボッツ・テキスト:サイトの入口に貼る「入らないで」の張り紙)で、そのページを止めていないか。書き方は「[AIクローラーとrobots.txt](/aio/ai-crawler-robots-txt/)」で説明しています
- ページのソースに `noindex`(「棚に並べないで」という印)が入っていないか
- ログインしないと見られないページになっていないか

当サイトの [AIO診断ツール](/aio-checker/) にURLを入れると、robots.txt と noindex をまとめて確かめられます。

### 4. 中身と、サイトの中のつながりを見直す

ブロックがないのに大事なページが並ばないときは、ページの中身を見直します。ここからは Google のヘルプに書かれていることではなく、当サイトがすすめる見直しのポイントです。

- **そのページにしかない答え・情報があるか**:ほかのページやほかのサイトとほとんど同じ中身なら、棚に並べる理由がありません。自分で試した結果や実際の数字を足しましょう(「[一次情報の入れ方](/seo/first-party-information/)」)
- **サイトの中からリンクされているか**:関連する記事やトップページから1〜2本つなぎます

直したら、URL 検査の「インデックス登録をリクエスト」を押しておくと、読みに来てもらうきっかけになります。ただし押しても登録が約束されるわけではなく、何度も押す必要はありません。

## 新しいサイトは特に「時間」と「質」 [中級]

同じ週に、Google のジョン・ミューラーさん(検索の担当者)は、Bluesky(SNS)で、新しいサイトのページがなかなか登録されないという相談に、こう答えています(2026年11月10日、[Search Engine Roundtable](https://www.seroundtable.com/google-new-sites-time-value-42489.html) の報道で確認)。

- 新しいサイトは、Google のしくみがその **独自の価値を理解するのに時間がかかる** ことがある
- だから、**数より質** で、本当に良いものにしておくのがよい
- インデックス登録のリクエストに頼るより、ふつうのクロールと登録の流れに任せるのがよい

図書館のたとえでいえば、はじめて本を持ちこんだ人の本は、司書さんが「この本は、ほかの本にない何を教えてくれるか」をつかむまで、棚に並ぶのに時間がかかる、ということです。どれくらい待てばよいかの目安は「[SEOは時間がかかるって本当?](/seo/how-long-seo-takes/)」にまとめています。

当サイト(2026年11月9日公開)も、公開の翌日の時点で、記事のページは「検出 - インデックス未登録」(場所は知られたが、まだ読みに来ていない段階)でした。「クロール済み」の一つ手前の段階です。

## ヘルプの文章とレポートの細部 [上級]

### 「検出」と「クロール済み」のちがい

似た名前の状態が2つあります。どちらも2026年11月10日に日本語版のヘルプで確認した内容です。

| 状態 | Google のヘルプの説明 | 図書館では |
|---|---|---|
| 検出 - インデックス未登録 | ページは検出されたが、まだクロールされていない。通常は、サイトに負荷がかかりすぎると予想されたため、クロールを後に回した。そのため最終クロール日が空欄 | 本があることは知っているが、まだ読んでいない |
| クロール済み - インデックス未登録 | ページはクロールされたが、インデックスには登録されていない | 読んだけれど、棚に並べなかった |

「検出」は **読みに来る前**、「クロール済み」は **読んだ後** の判断です。直すところがちがいます。「検出」が長く続くなら、サイトの中のリンクやサイトマップ(「[XMLサイトマップとは?](/seo/xml-sitemap/)」)を見直します。「クロール済み」なら、そのページの中身や、ほかのページとの重なりを見直します。

### 書き換えで「消えた」ことの読み方

- **「送り直す必要はない」が消えた**:送り直しが必要になった、という意味ではありません。説明の書き方が「やらなくてよいこと」から「やるとよいこと(重要なページだけ診断)」に変わった、と読むのが自然です。
- **「質」という言葉は出てこない**:報道は、Google がこれまで質の問題でもこの状態になると説明してきたのに、新しい説明には書かれていない点を指摘しています。ヘルプが挙げる例はクローラーのブロックだけです。中身の見直しは、当サイトの考えとして書いています。

### 報告フォームを使うのはどんなとき?

新しい説明は、問題を十分に調べたうえで、**サイト全体の問題によるインデックス登録の不具合** が疑われるときに、[インデックス登録に関する問題を報告するフォーム](https://support.google.com/webmasters/contact/indexing_issue_form)を使うよう案内しています。1ページだけ並ばない、という相談の窓口ではありません。たとえば、ブロックも noindex もないのに、サイトのほとんどのページが急にこの状態になった、というときです。

### 数を追うときの注意

- 「ページ」の画面の数は、毎日ぴったり最新ではありません。数日のずれがあります
- 数が増えても、増えたのが一覧ページやパラメータつきURL(`?sort=new` のような印のついたURL)ばかりなら、気にしなくてかまいません
- 判断するときは、数ではなく **大事なページが入っているかどうか** を見ます。表をエクスポート(書き出し)して、自分の大事なURLの一覧と照らし合わせると早いです

## よくある質問

### 「クロール済み - インデックス未登録」は放っておいていいですか?

大事でないページなら、そのままで大丈夫です。Google のヘルプは「多くのサイトでよく見られる」「必ずしも問題ではない」と説明しています。検索に出てほしい大事なページだけ、URL 検査で原因を確かめてください。

### 待っていれば、いつか登録されますか?

約束はありません。書き換え前のヘルプには「いずれ登録されるかもしれない」とありましたが、今の説明からはなくなりました。大事なページなら、待つだけでなく、ブロックや中身のかぶりがないかを確かめるのがおすすめです。

### 「インデックス登録をリクエスト」を何度も押せば早くなりますか?

何度押しても早くはなりません。直したあとに1回押せば十分です。Google のミューラーさんも、リクエストに頼るより、ふつうのクロールと登録の流れに任せるのがよいと話しています(海外メディアの報道で確認)。

### 「検出 - インデックス未登録」とはどうちがいますか?

「検出」は、Google がページの場所を知っているけれど、まだ読みに来ていない状態です。「クロール済み」は、読みに来たうえで、登録しなかった状態です。くわしくは上の「[上級]」の章の表を見てください。
